🚀 Nexus AI — AI Website Builder
Full Product PRD (Architecture + Pipeline + UX + Implementation)
________________


1. Product Definition
1.1 Product Vision
Nexus AI is an AI front-end architect and builder pipeline that converts natural language prompts into production-grade websites through staged reasoning, planning, asset intelligence, and component generation.
The system simulates:
designer → UX architect → design system creator → frontend engineer → reviewer
instead of naive HTML generation.
________________


1.2 Core Value Proposition
“Generate real websites — not AI templates.”
Key differentiators:
* structured reasoning pipeline

* design system synthesis

* asset-aware generation

* modular component architecture

* iterative refinement

________________


2. System Architecture Overview
2.1 Pipeline Philosophy
All generation is staged.
User Prompt
 → Intent Reasoner
 → Site Architecture Planner
 → Design System Generator
 → Asset Intelligence Layer
 → Component Generator
 → Code Assembler
 → QA Evaluator
 → Preview Renderer


Each stage outputs structured JSON → feeds next stage.
No monolithic AI output.
________________


3. Prompt → Architecture Schema
3.1 Input Normalization Schema
User prompt is transformed into:
{
  "goal": "",
  "audience": "",
  "tone": "",
  "primary_action": "",
  "site_type": "",
  "complexity_level": "",
  "content_requirements": [],
  "visual_preferences": []
}


This ensures downstream determinism.
________________


3.2 Architecture Plan Schema
Planner outputs:
{
  "sections": [
    {
      "name": "Hero",
      "purpose": "",
      "components": [],
      "priority": "high"
    }
  ],
  "layout_strategy": "",
  "responsive_rules": "",
  "interaction_notes": ""
}


________________


4. LLM Pipeline Prompts
Each agent has a narrowly scoped prompt.
________________


4.1 Intent Reasoner Prompt
Goal:
Convert user language → structured site intent.
Prompt skeleton:
Analyze the website request. Extract audience, goals, tone, user journey, and required sections. Output JSON only. Do not generate code.
________________


4.2 Architecture Planner Prompt
Given intent JSON, design section hierarchy, UX flow, and layout logic. Emphasize clarity and conversion. Output structured architecture plan.
________________


4.3 Design System Prompt
Generate cohesive design tokens: typography scale, spacing rhythm, palette, component styling rules. Avoid generic gradients.
________________


4.4 Component Generator Prompt
For each section, produce modular, semantic, maintainable frontend components aligned with the design system.
________________


4.5 QA Evaluator Prompt
Evaluate structure, consistency, responsiveness, and UX clarity. Suggest corrections or regenerate weak components.
________________
